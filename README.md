# MyMarketing

Plataforma para empresas planejarem publicacoes, centralizarem canais sociais e acompanharem performance de anuncios em um unico lugar.

## Estrutura

- `apps/web`: frontend em Next.js.
- `apps/api`: backend em Node.js com Express.
- `supabase/schema.sql`: schema inicial para Postgres/Supabase.
- `docs/SETUP.md`: passos de configuracao e variaveis de ambiente.

## Scripts

```bash
npm install
npm run dev
```

O frontend roda em `http://localhost:3000` e a API em `http://localhost:3333`.
